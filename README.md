# 📖 Overview

VidyarthiBus is an Android application developed to simplify student transportation management and improve the bus tracking experience for students and administrators.

The application provides real-time bus information, student-friendly navigation, secure authentication, and an easy-to-use interface for accessing transportation-related updates.

This project was developed using Android Studio with Firebase integration for backend services and authentication.

# 🚀 Getting Started

## Prerequisites

Before running this project, make sure you have:

- Android Studio Installed
- Java JDK Installed
- Firebase Project Setup
- Android Device or Emulator

---

# ⚙️ Installation Steps

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Pratham808/VidyarthiBus.git
```

---

## 2️⃣ Open Project

Open Android Studio and select:

```bash
Open Existing Project
```

Choose the cloned folder.

---

## 3️⃣ Sync Gradle

Wait for Gradle synchronization to complete.

---

## 4️⃣ Firebase Setup

Connect the project to Firebase:

- Go to Firebase Console
- Create a Firebase Project
- Add Android App
- Download `google-services.json`
- Place it inside:

```bash
app/
```

---

## 5️⃣ Run Application

Click ▶ Run in Android Studio.
